# CODESYS SymbolConfig Clean Tool

Графическая утилита на Python (PyQt6) для очистки и адаптации файлов символьной конфигурации (`Symbolconfiguration.xml`), экспортированных из среды промышленной автоматизации **CODESYS V3.5**.

## Зачем нужна эта программа

При экспорте списка тегов (переменных ПЛК) из современных версий CODESYS V3.5 SP17+ в XML-файл добавляются избыточные служебные теги и метаданные. Из-за этого многие SCADA-системы, панели оператора (HMI) и OPC-серверы не могут корректно распарсить файл при импорте.

Программа автоматически приводит XML-файл к совместимому виду:
* **Удаляет лишние теги `<Attribute>`** внутри узлов `<Node>`, очищая структуру от комментариев и служебных флагов.
* **Сохраняет критически важный атрибут `qualified_only:=`**, чтобы сохранялась строгая адресация переменных (например, `PLC_Tag.gaz_valve`).
* **Сворачивает пустые теги `<Node>...</Node>`** в компактный самозакрывающийся формат `<Node ... />`.
* **Нормализует заголовок и форматирование**, приводя документ к стандарту `<?xml version="1.0" encoding="utf-8"?>` с отступами и переносами строк Windows (`CRLF`).

## Требования к окружению (для запуска из исходников)

* **Python 3.9** или новее (используется встроенная функция `ET.indent`).
* Библиотека **PyQt6**.

---

## Установка и запуск из исходного кода

1. **Клонируйте репозиторий или скачайте файлы проекта** в отдельную папку (например, `C:\Projects\CODESYS_XML_Cleaner`).
2. **Установите зависимости** через терминал (командную строку):
   ```bash
   pip install PyQt6
   ```
3. **Запустите приложение**:
   ```bash
   python main.py
   ```
   *(Замените `main.py` на актуальное имя вашего `.py` файла, если оно отличается).*

---

## Как пользоваться программой

1. Перетащите исходный `.xml` файл в окно программы или кликните по области загрузки, чтобы выбрать его через проводник.
2. Нажмите кнопку **«Сохранить как...»** и укажите имя и папку для итогового файла (расширение `.xml` добавится автоматически).
3. Нажмите **«Конвертировать XML»**. После завершения появится уведомление об успешном сохранении.

---

## Сборка автономного `.exe` файла (Windows)

Чтобы запускать программу на рабочих ПК и инженерных станциях без установленного Python, её можно упаковать в один исполняемый `.exe` файл с помощью **PyInstaller**.

1. **Установите PyInstaller**:
   ```bash
   pip install pyinstaller
   ```
2. **Перейдите в директорию с проектом**:
   ```bash
   cd C:\Projects\CODESYS_XML_Cleaner
   ```
3. **Выполните команду сборки**:
   ```bash
   pyinstaller --onefile --windowed --name="CODESYS_XML_Cleaner" main.py
   ```
   * `--onefile` — упаковывает скрипт и все библиотеки PyQt6 в один файл.
   * `--windowed` — скрывает фоновое окно консоли при запуске приложения.
   * `--name` — задаёт имя итогового `.exe` файла.
   * *(Опционально)* Если у вас есть файл иконки `icon.ico`, добавьте флаг `--icon="icon.ico"`.

4. **Получение результата**:
   Готовый файл `CODESYS_XML_Cleaner.exe` появится в автоматически созданной папке **`dist/`**. Временные файлы из папок `build/` и файл `.spec` можно удалить.
